# Basic Weather App

## Description
This is a simple Python Weather Application that fetches real-time weather information using the OpenWeatherMap API.

## Features
- Enter a city name
- Displays temperature in Celsius and Fahrenheit
- Displays humidity
- Displays weather condition
- Displays wind speed
- Handles invalid city names and network errors

## Technologies Used
- Python
- Requests Library
- OpenWeatherMap API
